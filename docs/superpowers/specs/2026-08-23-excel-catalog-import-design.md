# Excel 基础数据导入设计

## 目标

在“基础数据”页面提供完全离线的 Excel 导入能力，支持附件所示的教师表和课程要求表。导入结果先进入前端草稿，经用户预览确认后合并到页面；只有用户随后点击“保存基础数据”时，数据才通过现有接口写入本机 JSON。

## 输入格式

### 教师表

必需表头：

- `教师姓名`
- `班主任班级`
- `主教学科`

空白的班主任班级允许导入。教师姓名和主教学科不能为空。

### 课程要求表

必需表头：

- `班级`
- `科目`
- `教师`
- `教室`
- `周课时`
- `连堂课时`
- `固定时间（星期*节次）`

导入时忽略“连堂课时”的具体数值，新建课程要求统一使用 `consecutive_periods: 1`。基础数据页面不再显示连堂课时输入项，但已有课程要求中非 1 的历史值在普通编辑和保存过程中保持不变。

固定时间使用一基编号，例如 `1*8` 表示周一第 8 节；`/` 或空白表示没有固定时间。允许用中文逗号、英文逗号、顿号、分号分隔多个固定时间。

## 解析与识别

浏览器使用项目已有的 ExcelJS 读取 `.xlsx` 文件，不向服务器上传文件。导入弹窗提供“教师信息”和“课程要求”两个文件入口，也允许只导入其中一种。系统按规范化后的表头识别文件类型；表头缺失、工作表为空、单元格类型非法时阻止应用，并报告工作表、行号、列名和原始值。

字符串字段去除首尾空格。数字字段接受 Excel 数值和纯数字字符串，但周课时必须为正整数。工作簿中完全空白的行被忽略。

## 名称映射与合并

所有引用均按去除首尾空格后的显示名称匹配，区分不同文字，不使用模糊匹配。

- 同名教师：更新现有教师，不创建副本；非空的班主任班级和主教学科覆盖对应字段，同时保留教师已有的不可用时间、任课关联和其他科目资质。
- 教师表中的新教师：创建教师，并将主教学科加入资质科目。
- 课程要求引用的班级、科目、教室不存在时：自动创建对应基础数据，并在预览中单独计数。
- 课程要求引用的教师不存在时：自动创建教师，并将该课程的科目加入资质；教师已存在时补充该科目资质。
- 相同“班级 + 科目”的课程要求：更新现有要求的教师、教室、周课时、固定时间，保留其 ID 和历史连堂值。
- 新课程要求：创建新 ID，`consecutive_periods` 固定为 1。
- 导入不会删除表格中未出现的现有数据。

同一工作簿中出现重复但内容一致的教师行或课程要求行时，只处理一次并显示为跳过；重复键对应内容冲突时阻止应用，并把每个冲突行的位置列出。

## 用户流程

1. 用户在基础数据页点击“导入 Excel”。
2. 在弹窗中选择教师表、课程要求表或两者。
3. 解析期间按钮和文件区域显示加载状态，禁止重复操作。
4. 系统显示预览摘要：新增、更新、跳过以及错误数量，并展示将新增的班级、科目、教师、教室和课程要求。
5. 只要存在阻断错误，“应用到草稿”按钮就不可用。
6. 用户应用后，导入实体放到各列表首位并沿用现有新增动画；页面显示成功提示。
7. 用户点击现有“保存基础数据”按钮后才持久化；保存失败仍使用现有结构化错误面板定位。

关闭弹窗或解析失败不修改当前表单。导入应用作为一次不可分割的前端状态更新，不产生部分导入。

## 代码边界

- 新增独立 Excel 解析与合并模块，避免把格式处理塞进大型 `CatalogPage.jsx`。
- 新增独立导入弹窗组件，只负责文件选择、预览和确认。
- `CatalogPage.jsx` 只负责打开弹窗、接收合并后的草稿、触发已有新增定位动画。
- 后端 API、JSON 存储格式和排课求解器不改动。
- 使用现有 `exceljs` 依赖，不新增运行时依赖。

## 错误呈现

解析错误采用结构化对象，至少包含：`fileType`、`sheetName`、`row`、`column`、`value`、`message`。界面统一渲染为可读中文，例如：

`课程要求.xlsx → Sheet1 → 第 3 行 → 周课时：必须是正整数（原值：abc）`

不得直接把对象传给 toast 或 JSX 文本节点，避免出现 `[object Object]`。

## 测试与验收

- 单元测试覆盖表头识别、空行、数字转换、`/`、`1*8`、多个固定时间和错误位置。
- 单元测试覆盖同名教师更新、自动创建引用实体、资质补充、课程要求更新、冲突重复以及不删除原数据。
- 组件测试覆盖选择文件、加载状态、错误阻断、预览摘要、应用草稿和取消不修改。
- 页面测试覆盖导入按钮、导入后列表首位以及保存仍走原有 `updateCatalog`。
- 隐藏课程要求连堂输入，并验证手动新增和导入的新要求均为 `consecutive_periods: 1`。
- 运行前端定向测试、完整测试、ESLint 和生产构建。
